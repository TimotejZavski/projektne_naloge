# RAI client

Frontend skeleton za SCRUM-25 prikaze osnovni dashboard za pametno igralisce
in pripravi Mapbox static map prikaz.

## Zagon

```bash
npm install
npm start
```

## Mapbox

1. Kopiraj `.env.example` v `.env`.
2. V `REACT_APP_MAPBOX_TOKEN` vpisi public Mapbox token.
3. Ponovno zazeni `npm start`.

Ce token ni nastavljen, aplikacija prikaze nadomestni map panel.
